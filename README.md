# 💫 About Me:
Я **Data Analyst** с глубоким интересом в сфере **Data Science, Machine Learning и Automation**. 
Мне нравится превращать сырые данные в понятные инсайты, оптимизировать рутину и создавать масштабируемые автоматизированные решения.

- 📊 **Анализ и Визуализация:** Проектирую понятные интерактивные дашборды и собираю аналитические пайплайны.
- 🤖 **ML & MLOps:** Обучаю предиктивные модели и настраиваю логирование/трекинг экспериментов.
- ⚙️ **Автоматизация и DevOps:** Пишу скрипты для автоматизации задач, разворачиваю контейнеры и строю инфраструктуру для Умного Дома.
