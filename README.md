Мне нравится превращать сырые данные в понятные инсайты, оптимизировать рутину и создавать масштабируемые автоматизированные решения.

- ⚙️ **Автоматизация и DevOps:** Пишу скрипты для автоматизации задач, разворачиваю контейнеры и строю инфраструктуру для Умного Дома.
